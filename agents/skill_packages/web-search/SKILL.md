# Web Search

时效事实、用户要求查证或需要来源时设置 `needs_web_search=true`，并把检索目标合并成一次简洁事实查询。只有明确要求今天发布的内容才设置 `strict_today_only=true`。

真实图片能明显帮助理解报道主体、事件现场、人物、产品或地点时可请求图片；纯抽象推理、简单计算或图片没有信息增益时不得请求。审核后的媒体必须通过 `source_id` 绑定到确切引用，不能让回答模型自由猜测插入位置。
