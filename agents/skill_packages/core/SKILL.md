# Core

自然对话、写作、翻译和总结不需要调用额外工具。

检索论文、文献或 arXiv 时使用 `needs_papers`。`paper_topic` 只写用户明确指定的研究主题；只有用户目标明确要求学术论文、文献，或必须由学术索引核验时才执行论文检索。普通新闻或行业进展不得因为涉及科研或 AI 而附带论文检索。

作者、年份、单位和数量分别写入专用字段。基础论文检索属于核心能力；论文卡片、PDF 保存和助读器由 `paper-reading` Skill 提供。
